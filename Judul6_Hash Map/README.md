# Sistem Reservasi Hotel

# a. Judul Program
Sistem Reservasi Hotel

# b. Deskripsi Singkat
Program ini merupakan implementasi Hash Map dalam Python untuk mengelola data reservasi hotel. Setiap nomor kamar digunakan sebagai key, sedangkan informasi tamu seperti nama, lama menginap, dan status reservasi disimpan sebagai value. Dengan menggunakan Hash Map, proses pencarian, penambahan, perubahan, dan penghapusan data reservasi dapat dilakukan dengan cepat dan efisien. Sistem ini membantu pengelolaan data tamu hotel secara terstruktur berdasarkan nomor kamar.

# Penjelasan code
Program tersebut menerapkan Hash Map menggunakan struktur data dictionary Python untuk menyimpan data reservasi hotel. Dictionary bernama reservasi berisi nomor kamar sebagai key dan informasi tamu seperti nama, lama menginap, serta status reservasi sebagai value. Program kemudian menjalankan perulangan while True agar menu dapat ditampilkan terus-menerus sampai pengguna memilih keluar. Pada menu pertama, program menampilkan seluruh data reservasi dengan melakukan perulangan menggunakan for. Pada menu kedua, pengguna dapat mencari data berdasarkan nomor kamar. Program akan memeriksa apakah nomor kamar tersebut terdapat dalam dictionary menggunakan operator in, kemudian menampilkan data tamu jika ditemukan.

Pada menu ketiga, pengguna dapat menambahkan data reservasi baru dengan memasukkan nomor kamar, nama tamu, dan lama menginap. Data yang dimasukkan kemudian disimpan ke dalam dictionary dengan nomor kamar sebagai key dan informasi tamu sebagai value. Jika pengguna memilih menu keempat, program akan menghentikan perulangan menggunakan perintah break dan menampilkan pesan bahwa program selesai. Penggunaan Hash Map pada program ini membuat proses pencarian, penambahan, dan pengelolaan data reservasi menjadi lebih cepat dan efisien karena data dapat diakses langsung melalui nomor kamar tanpa perlu mencari satu per satu.

Output program menampilkan menu utama yang berisi pilihan untuk melihat data kamar, mencari data kamar, menambah reservasi, atau keluar dari program. Jika pengguna memilih melihat data kamar, program akan menampilkan seluruh informasi reservasi yang tersimpan, seperti nomor kamar, nama tamu, lama menginap, dan status reservasi. Jika memilih mencari data kamar, program akan menampilkan detail reservasi sesuai nomor kamar yang dimasukkan apabila data tersedia, atau memberikan pesan bahwa kamar tidak memiliki reservasi jika tidak ditemukan. Saat pengguna menambahkan reservasi baru, program akan menyimpan data yang dimasukkan dan menampilkan pesan bahwa reservasi berhasil ditambahkan. Program akan terus menampilkan menu hingga pengguna memilih opsi keluar, kemudian program menampilkan pesan bahwa program telah selesai dijalankan.
